# Changelog

## 0.1.0, unreleased

- Initial desktop workspace for locally saved AI conversations and provider profiles.
- Native streaming adapters for OpenAI Responses, OpenAI-compatible Chat Completions, Anthropic Messages, Gemini and Azure OpenAI v1.
- Model discovery where supported, with manual model and deployment identifiers.
- Operating-system-protected API key storage in the main process.
- Optional bounded workspace reads and explicit approval for writes and commands.
- Windows x64 packaging with an original application icon and unsigned Squirrel.Windows installer.

This is a local initial build, not a published release. See `HANDOFF.md` for observed verification and remaining limitations.
