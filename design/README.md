# Harness interface intent

Harness is a local desktop AI workspace built with React and TypeScript. Its visual language uses Material Design 3 inspired color roles, lavender accents, generous component shapes, clear focus states, and compact desktop navigation. These files describe implementation intent, not captured runtime evidence.

## Design route limitation

The required Material Designer creation, export, and handoff flow was unavailable: no callable tool or packaged executable was discovered by the owning task. The implementation therefore uses checked-in source and this state inventory. No design preview or synthetic image is presented as application evidence.

## Addressable states

- Startup loading, failed bootstrap and retry.
- Empty conversations, quick starters, composer and profile selection.
- Saved messages, safe Markdown, streaming, cancellation and errors.
- Tool approval preview, allow and deny.
- Conversation tabs, actions, rename, delete confirmation and export.
- Provider presets, profile edit, transient password entry, model listing and removal.
- Appearance, language, motion, generation and tool settings.
- Help, privacy, JSON import and command palette.
- Conversation search and independent command search, each with an adjacent builder.

## Verification handoff

Minimum supported desktop client width is 860px. Capture the real built application in light and dark themes, English, Cantonese and bilingual modes, at 100%, 125%, 150% and 200% display scales. Inspect minimum and normal viewports. Bind every retained image to the exact source commit, build identity and viewport. Runtime captures are owned by the main task and are not yet present in this lane.

## Known contract gaps

The current localization covers navigation and conversation controls, not all provider, settings and help copy. Playfulness changes the greeting but does not yet vary every surface at every level. The universal school mode, personal vocabulary loader, Status Hub surface, full settings search, bulk actions and richer customization inventory remain unimplemented. These limitations must not be presented as completed global contract coverage.
